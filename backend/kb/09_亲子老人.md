# 亲子与老人游玩

## 带娃怎么玩

带 6 岁以下或身高 1.2 米以下儿童,推荐轻松路线:上午森林小火车环湖 → 湖畔亲子乐园(旋转木马、攀爬网、戏水浅滩) → 下午飞鸟剧场 14:30 场,全程平地为主,步行强度低。

1.2 米以下儿童免大门票,但彩虹滑道(限高 1.2 米)不能乘坐;亲子乐园部分项目限高 0.9 米以上。园区内可租赁婴儿车,主入口游客中心取还,30 元/天。

## 带老人怎么玩

60-69 岁老人门票 90 元,70 岁以上免票。推荐索道直接上主峰 → 云顶餐厅午餐看景 → 索道下山,或小火车环湖,避免云端栈道的长下坡台阶。

老人游玩建议避开周末 10:00-15:00 的高峰,随身携带常用药物,主入口和山腰广场均设医务室。

## 家庭一日参考路线

09:00 入园 → 09:20 索道上山 → 10:00 云栖主峰拍照 → 11:00 云端栈道慢走下山 → 12:00 山脚美食街午餐 → 13:30 亲子乐园/彩虹滑道(按孩子身高) → 14:30 飞鸟剧场 → 15:30 主街看花车巡游 → 16:30 小火车环湖 → 17:30 出园。

雨天可替换为:云栖水世界(室内恒温)+ 飞鸟剧场 + 山脚美食街,全部为室内或带顶棚区域。
